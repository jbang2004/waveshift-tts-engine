# Support

WaveShift TTS Engine is maintained as an early-stage open-source component.

Use GitHub issues for:

- reproducible bugs
- documentation gaps
- setup problems
- feature requests
- test coverage requests

Please include sanitized logs and environment details. Do not post credentials,
private media, private R2 URLs, or raw production task payloads.

For security issues, follow [SECURITY.md](SECURITY.md) instead of opening a
public issue.
